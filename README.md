Fall Out

Fall out is a 2D game Where user have to try not to fall too much the user have to land on different platform so that the player will not fall too much .


Features
- Game modes
- There are different type of game modes in the game
  --Puzzle mode : This help the player to understand how the game works
  --spinning mode : The whole scene is rotating it waas added so that the player can adpat to the game for the last mode
  --space mode : space mode is when the user use a very low gravity to move the falling impaact is very low
  --Destructionn mode : This is the last mode and cannot be complete, it is still in progress

-Power-Ups
--Slow Motion : slow player jumping and droping down
--Shield : Project the player from high fall
--Double Jump: allow the player to jump once on air

-Coin system : Coin is saved onn user storage and the user can use it to buy power ups in shop
-EXP system : allow the user to gain exp in each mode
